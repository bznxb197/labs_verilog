## APB slave

Базовый адрес устройства в тестбенче — `0x7000_0000`.

| Смещение | Регистр | Поведение |
|---|---|---|
| 0x0 | `register_with_some_name` | запись с `pwdata[0]=0` → хранится `0xAAAA_AAAA`, с `pwdata[0]=1` → `0x5555_5555` |
| 0x4 | `reg_date` | дата `дд.мм.гггг` в BCD, например `0x2910_2026` |
| 0x8 | `reg_surname` | первые 4 буквы фамилии в ASCII, `"Cher"` = `0x4368_6572` |
| 0xC | `reg_name` | первые 4 буквы имени в ASCII, `"Alex"` = `0x416C_6578` |
| другое | — | `pslverr = 1` |

О каждой операции slave и master печатают сообщение в консоль.
Тестбенч сам проверяет прочитанные значения и выводит `PASS`/`FAIL` и итоговое число ошибок.

## Запуск симуляции

Icarus Verilog:

```
sh run_icarus.sh            # обычный вывод
sh run_icarus.sh +monitor   # дополнительно вывод $monitor по шине
```

ModelSim / QuestaSim (в консоли симулятора):

```
do run_modelsim.do
```

## Исправления заготовки

1. Блок после `case` в конце `always` выполнялся на каждом такте и перезаписывал
   `register_with_some_name` по его же младшему биту. Из-за этого записанное значение
   терялось, и регистр всегда был `0xAAAA_AAAA`, даже после записи `1`.
   Теперь значение выбирается по `pwdata[0]` в момент записи.
2. `pslverr` после ошибки оставался равным 1 до сброса. Теперь он сбрасывается в `APB_SETUP`.
3. Добавлена директива `` `timescale 1ns/1ps ``: без неё задержка `#10ns` в Icarus
   округляется до 0 и тактовый генератор зацикливается.
4. В задаче чтения неблокирующее присваивание выходному аргументу (`data <= prdata`)
   заменено на блокирующее: в `automatic`-задаче NBA к локальной переменной недопустимо.
